🔴 XSS Vulnerable Page (innerHTML)

⚠️ VULNERABILITY DEMONSTRATION

This page is INTENTIONALLY vulnerable to demonstrate XSS attacks.

Vulnerable code pattern:

document.getElementById('welcome').textContent = 'Welcome ' + name;

The innerHTML property renders HTML, allowing script execution.

Simulated JWT Token (stored in localStorage):

In a real application, this token would grant access to protected resources. An XSS attack can steal this token and send it to an attacker's server.

How to Test the Vulnerability:

  1. Open this page with a safe parameter:
    vulnerable.html?name=Alice
  2. Try with an XSS payload (copy and paste into browser):
    vulnerable.html?name=<img src=x onerror="alert('XSS: Token is ' + localStorage.getItem('jwt_token'))">
  3. Observe that the JavaScript executes and displays the token in an alert

What Makes This Vulnerable?

  • innerHTML - Renders user input as HTML (not plain text)
  • No validation - User input is used directly without sanitization
  • URL parameter - Attacker can craft malicious URLs to send to victims

📝 Learning Objective: Compare this vulnerable page with secure.html to see how textContent prevents XSS.
