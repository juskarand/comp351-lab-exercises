✅ XSS Secure Page (textContent)

✓ SECURE IMPLEMENTATION

This page is protected against XSS attacks using proper HTML escaping.

Secure code pattern:

document.getElementById('welcome').textContent = 'Welcome ' + name;

The textContent property treats all input as text, preventing script execution.

Simulated JWT Token (stored in localStorage):

Even with the same localStorage token as the vulnerable page, XSS attacks cannot steal it because textContent prevents code execution.

How to Verify the Security:

  1. Open this page with a safe parameter:
    secure.html?name=Alice
  2. Try the SAME XSS payload that worked on vulnerable.html:
    secure.html?name=<img src=x onerror="alert('XSS: Token is ' + localStorage.getItem('jwt_token'))">
  3. Observe that the payload is displayed as TEXT, not executed as code
  4. No alert appears - the attack is neutralized!

textContent vs innerHTML Comparison:

Property Behavior Security
textContent Displays input as plain text ✅ Safe - No code execution
innerHTML Parses and renders HTML ❌ Vulnerable - Executes scripts

Why textContent Prevents XSS:

  • No HTML parsing - Browser treats input as literal text characters
  • Automatic escaping - Special characters like < and > are displayed, not interpreted
  • No event handlers - onerror, onclick, etc. are shown as text, not attached to elements
  • Same for Alpine.js - Using x-text is equivalent to textContent (secure)

Real-World Application:

In Activity 6, you'll verify that the Todo application uses secure patterns:

  • Flask Templates: {{ "{{" }} variable {{ "}}" }} automatically escapes HTML (like textContent)
  • Alpine.js: x-text="variable" uses textContent behavior (secure)
  • Avoid: {{ "{{" }} variable | safe {{ "}}" }} in Flask (like innerHTML - dangerous!)
  • Avoid: x-html="variable" in Alpine.js (like innerHTML - dangerous!)

📝 Learning Objective: Always use textContent (or x-text in Alpine.js) when displaying user-generated content. Only use innerHTML/x-html for trusted, sanitized content from your own application.
